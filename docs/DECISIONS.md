# CubeKorean 决策记录

## DEC-001：沿用现有前端技术栈

- 日期：2026-09-03
- 状态：已确认
- 决策：沿用React 19、TypeScript、Vinext和Vite，不因ADOS模板改写为Python项目。
- 原因：原型已经验证核心交互，继续演进的风险和成本最低。

## DEC-002：MVP采用本机进度

- 日期：2026-09-03
- 状态：已确认
- 决策：使用 `localStorage` 保存进度，暂不引入账号、API和数据库。
- 代价：无法多设备同步，清理浏览器数据会丢失进度。

## DEC-003：使用浏览器韩语TTS

- 日期：2026-09-03
- 状态：已确认
- 决策：MVP使用Web Speech API的 `ko-KR` 语音。
- 代价：声音质量和可用性因浏览器与系统而异，必须提供不阻塞拼写的回退。

## DEC-004：首个内容范围为日常饮食200词

- 日期：2026-09-03
- 状态：已确认
- 决策：一个大关卡包含10个小关卡，每关20词。
- 约束：内容上线前需要进行韩文拼写、中文释义、英文释义和发音适用性审核。
