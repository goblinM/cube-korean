# CubeKorean 产品需求（PRD）

## 1. 产品定位

CubeKorean 是一款以生活韩语拼写为核心、通过魔方关卡组织学习内容的网页应用。它不从字母教学开始，而是帮助已有少量基础的用户把词义和读音准确还原成韩文。

## 2. 目标用户

- 已认识基础韩文字母并能使用韩语输入法；
- 认识部分生活词汇，但容易出现元音、辅音或收音拼写错误；
- 希望通过短关卡持续练习，而不是只做选择题或背词卡。

## 3. 核心用户链路

```text
魔方选择生活主题 → 进入小关卡 → 看词拼写 → 听音拼写
→ 即时错误反馈 → 错词重练 → 收录错词本 → 专项复习 → 保存掌握度
```

## 4. 核心需求

### 4.1 关卡体系

- 一个大关卡对应一个生活主题；
- 每个大关卡包含10个小关卡；
- 每个小关卡包含20个词；
- 魔方负责主题展示与选择，学习顺序由课程配置控制，不采用完全随机教学顺序。

### 4.2 拼写训练

- 第一轮显示韩文、中文和英文，用户看词拼写；
- 第二轮隐藏韩文，自动播放读音，用户听音拼写；
- 中文默认显示，英文允许关闭；
- 正确输入显示黑色，未输入显示灰色，错误输入显示红色；
- 判断必须兼容韩语输入法的音节组合中间态；
- 错词进入本关复习，直到独立拼写正确。

### 4.3 错词本

- 听音拼写和专项复习中的错误按单词累计；
- 支持按大关卡和小关卡筛选，并直接启动听写复习；
- 显示错误次数、来源和专项复习进度；
- 连续两次专项复习一次答对后自动移出错词本。

### 4.4 发音与进度

- 使用 `ko-KR` Web Speech API，进入单词时默认朗读；
- 支持手动重播和关闭自动发音；
- MVP将关卡进度、首次正确率和错词保存在当前设备。

## 5. 首个大关卡

首个主题为“日常饮食”，规划10个小关卡：咖啡店与饮品、早餐、主食、水果、蔬菜、零食、餐厅点餐、味道与口感、厨房用品、综合听写挑战。

第二个主题为“日常出行”，包含公共交通、方向与问路、道路与驾驶、火车站、机场与登机、住宿、观光、旅行用品、票务与预约、求助与应急，共10关×20词。

第三个主题为“酒店住宿”，包含住宿基础、预订、前台沟通、房型、房间设施、卫浴用品、酒店服务、问题处理、费用与设施、入住与退房，共10关×20词。原“日常出行”住宿词条迁移到本章时保留原有词条ID，确保本机进度与错词记录继续有效。

## 6. 验收标准

- 用户能够完成20词的看词拼写、听音拼写和错词重练闭环；
- 一个大关卡包含10个可配置、可解锁的小关卡；
- IME输入 `ㅋ → 커 → 커ㅍ → 커피` 时不会误报错误；
- 刷新页面后仍能恢复本机学习进度；
- 手机和桌面端均可完成输入与通关；
- TTS不可用时页面不崩溃，并允许继续看词拼写；
- 拼写核心规则具备自动化测试。
- 错词本能够筛选600词课程中的错误记录，并在连续两次正确复习后移除。

## 7. 非目标

MVP不包含字母入门、完整语法课、AI对话、录音评分、排行榜、付费订阅、管理后台、账号体系、多设备同步或原生移动应用。
