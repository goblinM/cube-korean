# CubeKorean MVP

## 必须包含

- “日常饮食”一个大关卡；
- 10个小关卡，每关20词，共200词；
- 魔方关卡入口、顺序解锁和关卡完成状态；
- 韩文、中文、英文及英文开关；
- 看词拼写、听音拼写、错词重练；
- 韩语IME组合输入兼容和音节级颜色反馈；
- Web Speech API自动朗读、重播和静音；
- 首次正确率、错词和通关结果；
- `localStorage` 本机进度恢复；
- 手机与桌面端适配；
- 拼写规则与核心学习状态自动化测试。

## 当前原型已具备

- 魔方视觉入口；
- “日常饮食”10关×20词课程数据；
- 看词和听音两轮练习；
- 中英韩显示、TTS、颜色反馈及IME前缀判断；
- 响应式页面和线上部署。
- 错词重练、首次听写正确率和关卡结果页；
- 课程数据完整性、重复标识及10×20目标校验；
- 可独立测试的学习会话状态机。
- 小关卡选择、顺序解锁和完成状态；
- 本机进度、最佳首次听写正确率、尝试次数与错词持久化。
- 页面韩语键盘完整音节组合，以及TTS不可用时的可继续降级提示。

## 明确延后

账号、云同步、后端数据库、课程后台、真人录音、AI对话、口语评分、社交和商业化功能均不进入当前MVP。

## 完成定义

所有“必须包含”项完成，核心测试和生产构建通过，移动端主路径经过人工回归，PRD、TODO、CHANGELOG、DEBUG和DECISIONS同步更新。
