# CubeKorean MVP

## 必须包含

- “日常饮食”一个大关卡；
- 10个小关卡，每关20词，共200词；
- 魔方关卡入口、顺序解锁和关卡完成状态；
- 韩文、中文、英文及英文开关；
- 看词拼写、听音拼写、错词重练；
- 韩语IME组合输入兼容和音节级颜色反馈；
- Web Speech API自动朗读、重播和静音；
- 首次正确率、错词和通关结果；
- `localStorage` 本机进度恢复；
- 手机与桌面端适配；
- 拼写规则与核心学习状态自动化测试。

## 当前原型已具备

- 魔方视觉入口；
- 咖啡店与饮品5词演示数据；
- 看词和听音两轮练习；
- 中英韩显示、TTS、颜色反馈及IME前缀判断；
- 响应式页面和线上部署。

## 当前尚未具备

- 10×20正式课程内容；
- 多小关卡选择和解锁；
- 错词重练与结果页；
- 本机进度持久化；
- 拼写领域模块拆分及自动化测试。

## 明确延后

账号、云同步、后端数据库、课程后台、真人录音、AI对话、口语评分、社交和商业化功能均不进入当前MVP。

## 完成定义

所有“必须包含”项完成，核心测试和生产构建通过，移动端主路径经过人工回归，PRD、TODO、CHANGELOG、DEBUG和DECISIONS同步更新。
