- 状态：已确认，按章实施中（当前完成第1阶段：酒店住宿）

- 规模：10个大关卡 × 每关10个小关卡 × 每小关20词，共2000词

## 1. 规划目标

课程面向已掌握基础韩文字母、希望强化生活词汇拼写的学习者。内容从高频生存场景逐步过渡到工作、健康、兴趣和社交；每个单词仍使用“看词拼写 → 听音拼写 → 错词重练 → 错词本专项复习”的现有链路。

## 4. 每个小关卡的内容配比

每关20词采用目标配比，而非机械硬限制：

- 10～13个具体名词，先建立场景识别；
- 4～6个高频动词，覆盖场景动作；
- 2～4个形容词或状态词，支持描述与判断；
- 初期以1～3音节为主，后期逐步增加4～6音节词；
- 每关至少覆盖收音、复合元音或双辅音中的两类拼写难点；
- 完整句子和语法变形暂不作为词条，避免偏离拼写训练目标。

## 5. 全课程内容治理规则

1. 2000个词条使用全局唯一ID，韩文主词条原则上不重复。
2. 同一韩文存在多义时只保留一个主场景，其他场景使用引用说明，不重复出题。
3. 名词与对应动词可以分别收录，例如 `예약` 与 `예약하다`，但必须分配到最符合使用频率的关卡。
4. 外来语采用韩国通行标准拼写；口语俗称只能作为释义补充。
5. 中文释义优先表达当前场景含义，英文作为辅助，不参与答题。
6. 词条正式上线前检查韩文、中文、英文、读音适用性、重复项和输入长度。
7. 主要语言依据优先使用韩国国立国语院《韩国语基础词典》；未收录的新词需标记二次审核来源。

## 6. 现有课程迁移方案

当前数据不直接删除或重建，避免破坏用户本机进度和错词记录。

| 现有内容 | 目标去向 | 处理原则 |
|---|---|---|
| 日常饮食200词 | 保留在第1大关卡 | 仅调整第10关命名及后续内容校审 |
| 公共交通、问路、道路、铁路词 | 第2大关卡“交通出行” | 保留现有词条ID，重新分配小关卡 |
| 机场登机相关词 | 第2、3或4大关卡 | 交通方式留在交通；住宿和旅行流程分别迁移 |
| 酒店住宿20词 | 第3大关卡“酒店住宿” | 保留ID，已补齐至200词 |
| 观光与景点20词 | 第4大关卡“旅游景点” | 保留ID，补充其余180词 |
| 旅行用品20词 | 第4大关卡第10关 | 与已有生活用品去重 |
| 票务词 | 按交通票、景点票、购物支付拆分 | 一个韩文主词只保留一个归属 |
| 求助与应急词 | 第2、4、6大关卡 | 交通事故、旅行求助、医疗急诊分别归类 |

迁移时提供旧小关卡ID到新小关卡ID的映射；进度读取层负责兼容旧记录，错词以稳定的词条ID继续关联。

## 7. 实施顺序建议

1. 先确认本规划的十大主题、顺序和100个小关卡名称。
2. 建立课程级重复词校验和旧ID迁移测试。
3. 重组现有“日常出行”200词，但不改变稳定词条ID。
4. 已完成全部十章结构化数据；下一步进行逐章母语级校订。
5. 再按购物、医院、工作、运动、影视、社交顺序逐章补齐。
6. 每完成一个大关卡即进行内容审核、自动化校验和人工主路径回归，不等待2000词全部完成后一次上线。
