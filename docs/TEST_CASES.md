# CubeKorean 测试用例

## 1. 使用说明

本文档用于发布前回归和后续人工检查。自动化状态以最近一次 `npm run test:all` 为准；涉及真实扬声器、Safari和系统软键盘的项目仍需人工执行。

环境建议：

- 桌面：Mac Chrome最新版、Mac Safari最新版；
- 移动端：Chrome响应式视口390×844，另用一台真实手机检查软键盘；
- 数据：测试前导出学习备份，人工测试使用第一主题第一关，避免污染正式学习记录。

优先级：P0阻断发布，P1影响核心学习体验，P2属于视觉或增强检查。

## 2. 自动化执行

```bash
npm run lint
npm test
npm run test:e2e
```

也可以运行完整命令：

```bash
npm run test:all
```

## 8. 发布判定

满足以下条件才建议发布：

- `npm run test:all` 全部通过；
- P0自动化用例无失败；
- Mac Chrome和Safari音频人工试听通过；
- 390px真机不弹出非预期系统键盘；
- Git状态中不包含 `test-results/`、`playwright-report/`、密钥或临时音频文件。
